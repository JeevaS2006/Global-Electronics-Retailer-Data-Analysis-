# Excel and Power BI Data Analytics Mini Project

## 📌 Project Overview

This mini project focuses on performing real-world data analysis using Microsoft Excel and Power BI.

The project involves cleaning, transforming, and preparing raw datasets using Excel, followed by developing interactive dashboards and visual reports using Power BI.

The main objective is to transform raw data into meaningful business insights through effective data preparation, analytical techniques, and data visualization.

This project demonstrates my practical skills in data analytics and is part of my journey as an **Aspiring Data Analyst**.

## 🎯 Project Objectives

- Perform data cleaning and preprocessing using Microsoft Excel.
- Identify and remove duplicate records.
- Handle missing and inconsistent data.
- Standardize data formats for accuracy and consistency.
- Create calculated fields where required.
- Apply filtering and sorting techniques.
- Perform data summarization using Pivot Tables.
- Develop interactive dashboards using Power BI.
- Create meaningful visualizations to communicate business insights.
- Present analytical findings through clear and professional reports.

## 🔄 Project Workflow

### 1. Data Preprocessing Using Excel

The raw dataset was prepared and cleaned using Microsoft Excel to ensure data quality and consistency.

#### Data Cleaning
- Identified and removed duplicate records.
- Handled missing and blank values using appropriate strategies.
- Corrected inconsistent data entries.
- Standardized text, date, and numerical formats.
- Ensured consistency across relevant columns.

#### Data Transformation
- Created calculated fields where required.
- Applied filtering to extract relevant records.
- Sorted data for better organization and analysis.
- Prepared the dataset for further analytical processing.

#### Data Analysis
- Created Pivot Tables to summarize data.
- Aggregated relevant numerical values.
- Analyzed data across different categories.
- Identified patterns and trends to support business analysis.

### 2. Data Visualization Using Power BI

After preprocessing, the cleaned dataset was imported into Power BI for visualization and reporting.

#### Dashboard Development
- Created multiple visualizations to communicate analytical findings.
- Designed a clear and interactive dashboard layout.
- Used appropriate chart types based on the data and analytical objectives.
- Added meaningful titles, labels, and legends.
- Applied filters and slicers for interactive analysis.
- Organized visual elements to improve readability and presentation.
